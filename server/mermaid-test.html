2. 流程图 — 用户认证

flowchart TD
    A[用户请求] --> B{是否登录?}
    B -->|是| C[校验权限]
    B -->|否| D[跳转登录页]
    D --> E[输入账号密码]
    E --> F{验证通过?}
    F -->|是| C
    F -->|否| D
    C --> G{有缓存?}
    G -->|是| H[返回缓存数据]
    G -->|否| I[查询数据库]
    I --> J[写入缓存]
    J --> H
    H --> K[返回响应]

3. 时序图 — API 调用链

sequenceDiagram
    actor U as 用户
    participant W as Web前端
    participant G as API网关
    participant S as 业务服务
    participant D as 数据库
    U->>W: 点击查询按钮
    W->>G: POST /api/search
    G->>G: 鉴权 & 限流
    G->>S: 转发请求
    S->>D: SELECT * FROM items
    D-->>S: 返回结果集
    S-->>G: 处理后的数据
    G-->>W: JSON 响应
    W-->>U: 渲染列表
